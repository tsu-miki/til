# 既定値は事故を防ぐが、アクセス制御にはならない

一覧 API の既定を安全な部分集合にしても、クエリパラメータを付ければ誰でも全件を取れるので、渡してはいけない相手を止める手段にはならない。

```http
GET /resources?policy=all   # 誰でも付けられる。既定値は壁ではない
```

Saltzer と Schroeder の fail-safe defaults は、アクセスを「拒否の条件」ではなく「許可の条件」で判断する原則で、既定値ではなく認可の話。「うっかり混ぜてしまうのを防ぐ」なら既定値でよいが、「この利用者には渡してはいけない」なら認可で止める。

GDPR 25 条 2 項も、既定で必要な個人データだけを処理することと、本人の介在なしにアクセス可能にしないことの両方を求めている。
