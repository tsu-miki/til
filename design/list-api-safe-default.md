# 一覧 API が既定で全件を返さない設計は、標準化された選択肢

Google の API 設計指針 AIP-164 は、ソフトデリートしたリソースを一覧に既定で含めず、`show_deleted=true` を付けたときだけ返すと定めている。「一覧は全件、クエリパラメータで絞る」は慣習であって REST の要件ではない。

```http
GET /resources              # 既定はプライバシーポリシー適用後のみ
GET /resources?policy=all   # 明示的に適用前も含める
```

代償は、全件が必要な利用者が取りこぼしに気づけないこと。それでも既定を安全側に置くのは、取りこぼしは後から取り直せるのに対し、渡してしまった個人データは戻せない、という非対称性があるから。

真偽値の `include_xxx=true` より `policy=applied|all` のように取得範囲を名前で表すほうが、既定が何を指すか読み手に説明しやすい。

参照: https://google.aip.dev/164
