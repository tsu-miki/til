# グループの見え方は、余白の絶対値ではなく内と外の差で決まる

近接（関連する要素を近づけてグループにする）を成立させているのは余白をどれだけ取るかではなく、グループ内の余白がグループ間の余白より小さいという関係のほう。

```css
/* 商品名と価格は同じ商品の情報なので詰める */
.card__name { margin-bottom: 4px; }

/* カード同士は別グループなので広く空ける */
.card-list { display: grid; gap: 32px; }
```

商品名と価格の間隔がカード同士の間隔と同じだと、どの価格がどの商品のものか瞬時に判断できない。余白を一律に広げても関係が変わらないのでグループは生まれず、詰めるのは関連する側、空けるのは関連しない側になる。
