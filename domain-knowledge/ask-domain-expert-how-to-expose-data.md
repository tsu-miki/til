# 公開範囲がシビアなデータは、出す形をドメインに詳しい人に見てもらう

誰にどこまで見せてよいかは実装側だけでは決められないので、項目の可否を聞くのではなく、実際に返す形を見せて FB をもらう。

```json
// 「この形で返します」を先に出してレビューしてもらう
{
  "id": 42,
  "name": "山田 太郎",
  "affiliation": "◯◯支店",
  "note": "本人向けの補足"
}
```

項目単位で「出してよいか」だけ聞くと、粒度（フルネームか姓だけか）、並び、件数、他項目との組み合わせで誰か分かってしまう、といった観点が抜ける。仕様書に書かれていない前提は、その領域を長くやっている人の頭の中にしかない。決まった範囲は既定値ではなく認可で担保する。
