# 経歴と略歴は別物

経歴はこれまで経験してきた学業・仕事などの事柄そのもので、略歴はそれをおおまかにまとめたもの。

```markdown
経歴（時系列で網羅する）
- 2018/04 A 社 入社、受発注システムの開発
- 2021/10 B 社 入社、決済基盤のリプレース
- 2024/04 同社でチームリード

略歴（読ませる前提で短く）
- B 社で決済基盤のリプレースを担当。バックエンド 8 年。
```

大辞泉では経歴が「今まで経験してきた仕事・身分・地位・学業などの事柄」、略歴が「おおまかな経歴。また、それを記したもの」。画面や DB で両方を扱うときは、どちらの意味で使っているのかを先に確認する。
