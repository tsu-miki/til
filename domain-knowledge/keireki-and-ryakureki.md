# 会話で通じてしまう似た言葉ほど、項目にする前に意味の差を確かめる

日常では言い換えて済ませている 2 語が、画面や DB では別の項目として並ぶことがある。経歴と略歴がその例。

```markdown
経歴（時系列で網羅する）
- 2018/04 A 社 入社、受発注システムの開発
- 2021/10 B 社 入社、決済基盤のリプレース
- 2024/04 同社でチームリード

略歴（読ませる前提で短く）
- B 社で決済基盤のリプレースを担当。バックエンド 8 年。
```

大辞泉では経歴が「今まで経験してきた仕事・身分・地位・学業などの事柄」、略歴が「おおまかな経歴。また、それを記したもの」。片方がもう片方の要約なので、両方を持つなら「略歴は経歴から作るのか、別に書くのか」まで決めないと、更新のたびにずれる。

打ち合わせで通じた言葉は、確認されないまま実装に入りやすい。辞書で差が出る語は、その差がそのまま項目どうしの関係になる。
