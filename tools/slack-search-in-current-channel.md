# Slack の Ctrl+F は、開いているチャンネルの中だけを検索する

ブラウザのページ内検索の癖で押す Ctrl+F は、Slack では「今いる会話」に絞った検索が開く。

```text
Ctrl + F   今開いているチャンネル / DM 内を検索
Ctrl + G   ワークスペース全体を検索
Ctrl + /   ショートカット一覧を表示
```

Mac は Ctrl を ⌘ に読み替える。`in:#channel` を打ち直さずに済むので、「あの話どこだっけ」を今いる場所から辿れる。逆に全体を探したいときに Ctrl+F を使うと、チャンネル内に閉じたまま「見つからない」になる。

参照: https://slack.com/help/articles/202528808-Search-in-Slack
