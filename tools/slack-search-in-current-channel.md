# 「見つからない」ときは、検索語より先に検索範囲の既定値を疑う

検索窓はどれも既定の範囲を持っていて、それが自分の探したい範囲と一致しているとは限らない。Slack の Ctrl+F は、今開いている会話の中だけを検索する。

```text
Ctrl + F   今開いているチャンネル / DM 内を検索
Ctrl + G   ワークスペース全体を検索
Ctrl + /   ショートカット一覧を表示
```

Mac は Ctrl を ⌘ に読み替える。`in:#channel` を打ち直さずに済む一方、全体を探すつもりで押すと、チャンネル内に閉じたまま「見つからない」になる。

同じずれは grep（カレントディレクトリ以下）、エディタの検索（ファイル内かプロジェクト全体か）、GitHub の検索（リポジトリ内か全体か）でも起きる。ブラウザのページ内検索の癖で押しているときほど、範囲を自分で決めていない。

参照: https://slack.com/help/articles/202528808-Search-in-Slack
