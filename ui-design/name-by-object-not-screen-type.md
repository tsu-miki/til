# ユーザーに見せる名前は、実装の画面分類ではなく識別したい対象で決める

画面のタイトルはタブ・履歴・ブックマーク・検索結果で識別子として働くので、「Hoge詳細」のような実装側の画面分類ではなく、ユーザーが区別したい対象の固有名を先頭に置く。

```html
<!-- 実装側の画面分類。並んだタブのどれがどの Hoge か区別できない -->
<title>Hoge詳細</title>

<!-- 対象の固有名が先頭。一覧の中でも見分けられる -->
<title>〇〇株式会社 | Hoge</title>
```

一覧 / 詳細は CRUD 由来の実装側の分類であって、ユーザーの関心事ではない。ユーザーは画面種別を知りに来ているのではなく、対象そのものを見に来ている。画面種別を名前に残すのは、新規作成や検索結果のように対象が特定されない画面に限ると整理しやすい。「Hoge」が内部用語なら、ユーザーが普段使う呼び方に置き換える。
